Install

macOS

  1. Open the downloaded .dmg.
  2. Drag Folio into Applications.
  3. Open Folio and choose the folder you want to read.

Requires macOS 12 Monterey or later. Signed and notarized by Apple.

Windows

  1. Run the downloaded installer.
  2. If Windows SmartScreen says it protected your PC, choose More info, then Run anyway. The installer isn't code-signed yet.
  3. Open Folio from the Start menu.

Requires Windows 10 or later, 64-bit.

Linux

  1. Make the file executable: chmod +x Folio-*.AppImage
  2. Run it by double-clicking or from a terminal.
  3. On Ubuntu 22.04 and later, install FUSE first if it doesn't start: sudo apt install libfuse2

Requires a 64-bit x86 system.

Updates and older versions

Folio checks for new versions on its own and downloads them in the background. Restart when it asks, or the update installs the next time you quit. To check right away, choose Check for Updates from the Folio menu on a Mac, or the Help menu on Windows and Linux.

Release notes and every earlier version are on the GitHub releases page. To run Folio in a browser on your own server instead, follow the setup guide in the README.
