# Welcome

Welcome to **Folio** — a tool for browsing, reading and reviewing folders
of Markdown documents.

Use the panel on the left to navigate between documents. Click any file to render
it instantly in the viewer on the right. You can drag the divider to resize the
panels, or hide the sidebar entirely with the toolbar button or `⌘B` (`Ctrl+B`).

## Getting started

1. Drop any `.md` or `.markdown` files into this folder.
2. They appear in the list right away: Folio watches the folder while it's open.
3. Or open another folder with **File → Open Folder…** (`⌘O`).

Happy writing! ✨
