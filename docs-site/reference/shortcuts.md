# Keyboard shortcuts

| Action | macOS | Windows and Linux |
|---|---|---|
| Open folder | `⌘O` | `Ctrl+O` |
| Open in editor | `⌘E` | `Ctrl+E` |
| Reveal in Finder / Show in Folder | `⌥⌘R` | `Shift+Alt+R` |
| Settings | `⌘,` | `Ctrl+,` |
| Print | `⌘P` | `Ctrl+P` |
| Export as PDF | `⇧⌘E` | `Ctrl+Shift+E` |
| Toggle the sidebar | `⌘B` | `Ctrl+B` |
| Back / Forward | `⌘[` / `⌘]` | `Alt+Left` / `Alt+Right` |

## Reading

| Action | macOS | Windows and Linux |
|---|---|---|
| Find in the document | `⌘F` | `Ctrl+F` |
| Next / previous match | `⌘G` / `⇧⌘G` | `F3` / `Shift+F3` |
| Full-text search | `⇧⌘F` | `Ctrl+Shift+F` |

## Marking up

| Action | macOS | Windows and Linux |
|---|---|---|
| Highlight in the last colour | `⇧⌘H` | `Ctrl+Shift+H` |
| Bookmark the document | `⌘D` | `Ctrl+D` |
| Toggle inline notes | `⌥⌘N` | `Ctrl+Alt+N` |
| Copy review notes | `⇧⌘C` | `Ctrl+Shift+C` |

## The document list

| Key | Action |
|---|---|
| `↑` `↓` `Home` `End` | Move through the list |
| `→` `←` | Expand or collapse a folder |
| `Enter` | Open the document |
| `Escape` | Clear the folder focus |

## Diagrams and images in the whole window

| Key | Action |
|---|---|
| `+` / `-` | Zoom in or out (also `⌘` / `Ctrl` + scroll, or a pinch) |
| Arrow keys | Pan (also drag or scroll) |
| `0` | Fit and recentre |
| `1` | Actual size |
| `Escape` | Close |
